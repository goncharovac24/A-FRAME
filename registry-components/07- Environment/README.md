# Environment

## Objetivo
Criar ambientes virtuais em 3D.

## Funcionamento
O componente permite gerar cenários
com diferentes ambientes e elementos naturais.

## Componente
environment

## Dependências
- A-Frame 1.6.0
- aframe-environment-component

## Interação
Movimentar a câmara através do teclado e rato.

## Resultado esperado
Uma floresta 3D com montanhas e árvores.
