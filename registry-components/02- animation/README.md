
# Animation

## Objetivo
Demonstrar animações de objetos 3D.

## Funcionamento
Os objetos executam diferentes animações:
movimento, rotação e alteração de escala.

## Componente
A-Frame Animation (nativo).

## Dependências
- A-Frame 1.6.0

## Interação
Passar o rato sobre o cubo amarelo.

## Resultado esperado
Uma cena com vários objetos animados.
