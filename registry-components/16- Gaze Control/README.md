# Gaze Control

## Objetivo
Permitir interação através do olhar.

## Funcionamento
O sistema identifica o objeto para o qual
o utilizador está a olhar.

Quando o cursor permanece sobre um objeto
durante o tempo definido, ocorre uma seleção.

## Componente demonstrado
cursor com gaze/fuse.

## Dependências
- A-Frame 1.6.0

## Interação
Olhar para os objetos durante 1,5 segundos.

## Resultado esperado
Objetos que alteram de cor quando selecionados.
