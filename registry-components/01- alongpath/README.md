
# Alongpath

## Objetivo
Demonstrar o movimento de um objeto 3D
ao longo de um percurso predefinido.

## Funcionamento
Uma nave percorre automaticamente vários
pontos de uma trajetória curva.

## Componente
aframe-alongpath-component

## Dependências
- A-Frame 1.6.0
- aframe-curve-component

## Interação
Movimento automático em loop.

## Resultado esperado
Uma nave a percorrer continuamente
uma trajetória 3D.
