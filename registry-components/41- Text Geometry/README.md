# Text Geometry

## Objetivo
O Text Geometry permite criar texto tridimensional
através de geometria 3D.

## Funcionamento
O exemplo apresenta a palavra A-FRAME com profundidade
e efeito de relevo nas letras.

## Propriedades
- value: texto apresentado.
- font: tipo de letra.
- size: tamanho das letras.
- height: profundidade do texto.
- bevelEnabled: ativa o relevo das letras.

## Teste
Abrir o index.html e observar o texto 3D.

## Dependências
- A-Frame 0.9.0
- aframe-text-geometry-component 0.5.2
