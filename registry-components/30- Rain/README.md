# Rain

## Objetivo
O Rain cria um efeito de chuva numa cena 3D.

## Funcionamento
O componente gera gotas de chuva e salpicos
que caem sobre a cena.

## Teste
Abrir o index.html e observar o efeito da chuva.

## Dependências
- A-Frame 0.4.0
- aframe-rain 1.0.2

## Nota
O componente original foi desenvolvido para versões
antigas do A-Frame.
