# Physics System

## Objetivo
O Physics System adiciona propriedades físicas
aos objetos de uma cena 3D.

## Funcionamento
Os cubos utilizam dynamic-body para serem afetados
pela gravidade e pelas colisões.
O chão utiliza static-body para permanecer imóvel.

## Teste
Abrir o index.html e observar os cubos a cair
e a colidir com o chão.

## Dependências
- A-Frame 1.8.0
- @c-frame/aframe-physics-system 4.2.3

## Conceitos
- Gravidade
- Massa
- Colisões
- Corpos dinâmicos e estáticos
