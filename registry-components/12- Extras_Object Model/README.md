# Object Model

## Objetivo
Carregar objetos tridimensionais externos.

## Funcionamento
O componente permite importar objetos
através do THREE.ObjectLoader.

## Componente
object-model

## Dependências
- A-Frame
- aframe-extras.object-model
- Modelo JSON compatível com THREE.ObjectLoader

## Resultado esperado
Um objeto 3D externo apresentado
e animado numa cena A-Frame.
