# Point

## Objetivo
O Point cria pontos 3D utilizando THREE.Points.

## Funcionamento
O exemplo utiliza vários pontos para formar
uma pequena composição geométrica.

## Teste
Abrir o index.html e observar os pontos.

## Dependências
- A-Frame 0.5.0
- aframe-point-component 1.1.1

## Nota
O componente foi desenvolvido para versões antigas
do A-Frame e pode necessitar de ajustes em browsers atuais.
