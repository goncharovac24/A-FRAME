# Controller Cursor

## Objetivo
Criar um cursor laser controlado
por comandos VR.

## Funcionamento
O cursor permite apontar e interagir
com objetos no ambiente 3D.

## Componente
aframe-controller-cursor-component

## Dependências
- A-Frame 1.6.0
- Comandos VR compatíveis

## Interação
Apontar o comando para os objetos
e utilizar o botão de seleção.

## Resultado esperado
Um laser virtual para selecionar
objetos 3D.
