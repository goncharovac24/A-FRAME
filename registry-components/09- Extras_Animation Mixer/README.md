# Animation Mixer

## Objetivo
Reproduzir animações incluídas em modelos 3D.

## Funcionamento
O Animation Mixer permite controlar as animações
existentes em ficheiros glTF e GLB.

## Componente
animation-mixer

## Dependências
- A-Frame 1.6.0
- A-Frame Extras 7.2.0
- Modelo Fox.glb

## Interação
A animação é reproduzida automaticamente.

## Resultado esperado
Uma raposa 3D a executar uma animação.
