# Grid

## Objetivo
Criar uma grelha tridimensional.

## Funcionamento
O componente Grid disponibiliza uma grelha
quadrada para auxiliar na visualização
e organização de espaços 3D.

## Componente
grid

## Dependências
- A-Frame 1.6.0
- aframe-extras.grid

## Resultado esperado
Um espaço 3D com uma grelha e objetos
geométricos de referência.
