# Room

## Objetivo
O Room permite construir divisões e espaços
interiores em ambientes 3D.

## Funcionamento
O exemplo apresenta duas divisões com paredes
e materiais de cores diferentes.

## Elementos principais
- rw-room: cria uma divisão.
- rw-wall: define as paredes.
- rw-doorhole: define uma abertura para uma porta.
- rw-doorlink: liga duas portas.

## Teste
Abrir o index.html e observar as divisões.

## Dependências
- A-Frame 1.2.0
- aframe-room-component
