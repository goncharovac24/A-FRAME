# UI Widgets

## Objetivo
O UI Widgets disponibiliza elementos de interface
tridimensionais para experiências A-Frame.

## Funcionamento
O exemplo apresenta três elementos:
- ui-button: botão interativo.
- ui-toggle: interruptor.
- ui-slider: controlo deslizante.

## Teste
1. Abrir o index.html.
2. Utilizar o cursor para interagir com os elementos.
3. Observar as alterações dos indicadores.

## Dependências
- A-Frame 0.7.0
- aframe-ui-widgets 1.0.2

## Nota
A biblioteca foi desenvolvida para versões antigas
do A-Frame e pode necessitar de ajustes.
