# Lerp

## Objetivo
O Lerp permite criar transições suaves entre valores,
como posição, rotação e escala.

## Funcionamento
O exemplo apresenta um cubo que se desloca gradualmente
entre duas posições.

## Teste
Abrir o index.html num browser e observar o movimento.

## Dependências
- A-Frame
- aframe-lerp-component

## Nota
A animação apresentada utiliza o componente nativo
animation do A-Frame como demonstração visual.
