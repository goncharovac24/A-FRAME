
# Auto Detect Controllers

## Objetivo
Detetar automaticamente comandos VR.

## Funcionamento
O componente utiliza a Gamepad API
para identificar comandos compatíveis.

## Componente
aframe-auto-detect-controllers-component

## Dependências
- A-Frame 1.6.0
- Controladores VR compatíveis

## Resultado esperado
Deteção automática dos comandos
da mão esquerda e direita.
