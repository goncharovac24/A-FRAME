# Slice9

## Objetivo
O Slice9 permite redimensionar elementos gráficos
sem deformar os cantos da imagem.

## Funcionamento
O componente divide uma superfície em nove partes,
permitindo aumentar a área central.

## Teste
Abrir o index.html e observar o painel.

## Dependências
- A-Frame 0.4.0
- aframe-slice9-component

## Nota
O componente original é antigo e pode necessitar
de ajustes para funcionar em browsers atuais.
