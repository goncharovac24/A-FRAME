# Spritesheet

## Objetivo
O Spritesheet permite criar animações através
de uma sequência de imagens.

## Funcionamento
O exemplo utiliza uma spritesheet com quatro colunas
e uma linha de fotogramas.

## Preparação
Adicionar uma imagem chamada spritesheet.png
na mesma pasta do index.html.

A imagem deve conter:
- 4 colunas;
- 1 linha;
- 4 fotogramas com as mesmas dimensões.

## Teste
Abrir o index.html e observar a animação.

## Dependências
- A-Frame 0.5.0
- aframe-spritesheet-component
