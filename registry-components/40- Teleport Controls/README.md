# Teleport Controls

## Objetivo
O Teleport Controls permite deslocar o utilizador
entre diferentes posições de uma experiência VR.

## Funcionamento
O utilizador aponta o controlador para uma superfície
e ativa o teletransporte.

## Teste
1. Abrir a experiência num browser compatível com VR.
2. Ligar um controlador HTC Vive compatível.
3. Apontar para a plataforma de destino.
4. Ativar o botão de teletransporte.

## Dependências
- A-Frame 0.5.0
- aframe-teleport-controls 0.2.0

## Nota
O componente foi desenvolvido para versões antigas
do A-Frame e controladores VR específicos.
