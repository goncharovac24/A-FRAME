# Raytrace

## Objetivo
O Raytrace permite criar superfícies através de shaders.

## Funcionamento
O exemplo aplica um shader a um cubo,
criando uma superfície com tons magenta.

## Teste
Abrir o index.html e observar o objeto.

## Dependências
- A-Frame 0.6.0
- aframe-raytrace-component

## Nota
O componente utiliza uma versão antiga do A-Frame
e pode não funcionar corretamente em versões recentes.
