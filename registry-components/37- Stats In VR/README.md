# Stats in VR

## Objetivo
O Stats in VR permite visualizar informações
de desempenho da cena dentro do ambiente VR.

## Funcionamento
O exemplo apresenta os dados de desempenho
através do componente stats-in-vr.

## Teste
1. Abrir o index.html.
2. Observar as informações de desempenho.
3. Entrar em VR, se existir um equipamento compatível.

## Dependências
- A-Frame 0.4.0
- aframe-stats-in-vr-component 0.1.7

## Nota
O componente foi desenvolvido para versões antigas
do A-Frame.
