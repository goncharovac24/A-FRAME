# Crawling Cursor

## Objetivo
Demonstrar um cursor que acompanha
as superfícies dos objetos 3D.

## Funcionamento
O componente utiliza o raycaster
para detetar interseções com objetos.

## Componente
aframe-crawling-cursor

## Dependências
- A-Frame 1.6.0

## Interação
Mover a câmara e apontar para
diferentes superfícies.

## Resultado esperado
Um cursor amarelo que acompanha
as superfícies dos objetos.
