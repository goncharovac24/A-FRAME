# GearVR Controls

## Objetivo
Permitir a utilização do controlador Gear VR
num ambiente de realidade virtual.

## Funcionamento
O componente interpreta os comandos
do touchpad do controlador Gear VR.

## Componente
gearvr-controls

## Dependências
- A-Frame
- aframe-gearvr-controls-component
- Equipamento Gear VR compatível

## Resultado esperado
Uma cena VR preparada para receber
interações do controlador Gear VR.
