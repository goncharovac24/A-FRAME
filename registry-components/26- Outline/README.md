# Outline

## Objetivo
O Outline adiciona contornos aos objetos 3D,
destacando as suas formas.

## Funcionamento
O exemplo apresenta vários objetos com um efeito
de contorno aplicado à cena.

## Teste
Abrir o index.html e observar os contornos.

## Dependências
- A-Frame 0.7.1
- aframe-outline 1.1.1

## Nota
O componente original é antigo e poderá apresentar
problemas de compatibilidade em browsers atuais.
