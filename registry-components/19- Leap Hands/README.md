# Leap Hands

## Objetivo
O Leap Hands permite acompanhar os movimentos das mãos
do utilizador através de um sensor Leap Motion.

## Funcionamento
O componente original necessita de um dispositivo Leap Motion
e de compatibilidade com a versão antiga do A-Frame.

## Teste
A página apresenta uma cena demonstrativa.
O acompanhamento real das mãos não está ativo sem o sensor.

## Dependências
- A-Frame
- Leap Motion Controller
