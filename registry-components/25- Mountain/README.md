# Mountain

## Objetivo
O Mountain gera terrenos montanhosos em 3D
através de mapas de altura aleatórios.

## Funcionamento
O exemplo apresenta uma montanha com relevo
e iluminação direcional.

## Teste
Abrir o index.html num browser.

## Dependências
- A-Frame 0.3.0
- aframe-mountain-component 0.3.3

## Nota
O componente original foi desenvolvido para uma versão
antiga do A-Frame.
