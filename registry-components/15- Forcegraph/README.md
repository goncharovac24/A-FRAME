# Forcegraph

## Objetivo
Criar gráficos de relações em três dimensões.

## Funcionamento
O componente organiza nós e ligações
através de um sistema de forças.

## Componente
forcegraph

## Dependências
- A-Frame 1.6.0
- aframe-forcegraph-component

## Resultado esperado
Uma rede 3D com pontos e ligações
entre diferentes conceitos.
