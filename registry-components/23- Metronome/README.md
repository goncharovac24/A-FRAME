# Metronome

## Objetivo
O Metronome dispara eventos em intervalos regulares,
de acordo com o número de batidas por minuto (BPM).

## Funcionamento
O exemplo utiliza 120 BPM.
A esfera muda de cor e pulsa a cada batida.

## Teste
Abrir a página e observar a sincronização da esfera
com os eventos do metrónomo.

## Dependências
- A-Frame
- aframe-metronome-component
