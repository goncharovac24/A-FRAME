# JSON Model

## Objetivo
Carregar modelos 3D através de ficheiros JSON.

## Funcionamento
O componente utiliza o antigo THREE.JSONLoader
para interpretar modelos tridimensionais.

## Componente
json-model

## Dependências
- A-Frame
- aframe-extras.json-model
- Modelo JSON compatível com THREE.JSONLoader

## Resultado esperado
Um modelo 3D carregado numa cena A-Frame.
