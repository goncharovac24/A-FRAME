# Super Hands

## Objetivo
O Super Hands permite interagir com objetos 3D
através de gestos e controladores VR.

## Funcionamento
O exemplo apresenta dois objetos interativos.

Os principais comportamentos são:
- hoverable: deteta quando o utilizador aponta para o objeto.
- grabbable: permite agarrar o objeto.
- stretchable: permite esticar o objeto.
- drag-droppable: permite arrastar e largar objetos.

## Teste
Utilizar controladores VR compatíveis para experimentar
os gestos de interação.

## Dependências
- A-Frame 0.6.1
- A-Frame Extras 3.11.4
- Super Hands 2.0.1

## Nota
O exemplo utiliza bibliotecas antigas.
A compatibilidade com browsers e dispositivos atuais
não está garantida.
