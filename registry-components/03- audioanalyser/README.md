# Audioanalyser

## Objetivo
Explorar a análise de áudio em A-Frame.

## Funcionamento
O componente Audioanalyser utiliza a Web Audio API
para analisar frequências de áudio.

## Componente
aframe-audioanalyser-component

## Dependências
- A-Frame 1.6.0
- Audioanalyser
- Ficheiro music.mp3

## Resultado esperado
Reprodução de áudio e demonstração
de uma visualização 3D.
