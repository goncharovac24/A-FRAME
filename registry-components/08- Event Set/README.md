# Event Set

## Objetivo
Permitir alterações nos objetos através de eventos.

## Funcionamento
O componente Event Set permite modificar
propriedades dos objetos quando acontecem
eventos como mouseenter, mouseleave e click.

## Componente
event-set

## Dependências
- A-Frame 1.6.0
- aframe-event-set-component

## Interação
Passar o cursor e clicar nos objetos.

## Resultado esperado
Objetos que mudam de cor, tamanho e posição.
