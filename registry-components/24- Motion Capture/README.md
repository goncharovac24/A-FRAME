# Motion Capture

## Objetivo
O Motion Capture permite gravar e reproduzir
os movimentos realizados numa experiência VR.

## Funcionamento
O componente avatar-recorder permite iniciar
e terminar uma gravação dos movimentos.

## Como testar
1. Abrir a experiência num browser compatível.
2. Entrar em VR com os controladores disponíveis.
3. Pressionar a tecla Espaço para iniciar a gravação.
4. Movimentar a câmara e os controladores.
5. Pressionar novamente Espaço para terminar.
6. Guardar o ficheiro JSON da gravação.

## Dependências
- A-Frame 0.6.0
- aframe-motion-capture-components

## Nota
Este componente foi desenvolvido para versões antigas
do A-Frame. Pode não funcionar corretamente com versões
mais recentes.
