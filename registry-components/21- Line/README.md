# Line

## Objetivo
O componente Line permite desenhar linhas entre
dois pontos de uma cena 3D.

## Funcionamento
O exemplo apresenta três linhas com cores diferentes.

## Teste
Abrir o index.html e observar as linhas no espaço 3D.

## Dependências
- A-Frame

## Nota
Este exemplo utiliza o componente line nativo do A-Frame,
e não o componente externo original do Registry.
