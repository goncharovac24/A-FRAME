# Stereo

## Objetivo
O Stereo permite criar experiências estereoscópicas,
apresentando imagens diferentes a cada olho.

## Funcionamento
O exemplo utiliza:
- stereocam: define o olho utilizado pela câmara.
- stereo: define a que olho pertence cada objeto.

## Teste
Abrir o index.html e observar os dois objetos.
Para testar o efeito estereoscópico completo,
é necessário um equipamento VR compatível.

## Dependências
- A-Frame 1.7.0
- aframe-stereo-component 1.4.0
