# Shake2show

## Objetivo
O Shake2show permite mostrar ou esconder uma interface
através do movimento do telemóvel.

## Funcionamento
O componente utiliza o acelerómetro do dispositivo
para detetar movimentos de agitação.

## Teste
O exemplo está configurado com trigger: click
para permitir testar a interação num computador.

## Dependências
- A-Frame 0.7.0
- aframe-shake2show-component
- Shake.js

## Nota
Para testar a deteção de movimento real,
é necessário um dispositivo móvel compatível.
