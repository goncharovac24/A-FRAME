# Layout

## Objetivo
Organizar automaticamente vários objetos 3D.

## Funcionamento
O componente Layout distribui os elementos
de acordo com um padrão definido.

## Componente
layout

## Dependências
- A-Frame 1.6.0
- aframe-layout-component

## Interação
Visualizar a organização circular dos objetos.

## Resultado esperado
Seis objetos distribuídos automaticamente
numa composição circular 3D.
