# Tube

## Objetivo
Criar tubos tridimensionais ao longo de percursos.

## Funcionamento
O componente Tube permite gerar uma geometria
tubular seguindo uma trajetória personalizada.

## Componente
tube

## Dependências
- A-Frame 1.6.0
- A-Frame Extras 7.2.0

## Resultado esperado
Um percurso tubular neon em 3D.
