# Particle System

## Objetivo
O Particle System cria efeitos visuais através
de partículas animadas.

## Funcionamento
O exemplo utiliza o preset dust para criar
um efeito de partículas à volta de uma esfera.

## Teste
Abrir o index.html e observar as partículas.

## Dependências
- A-Frame 1.8.0
- aframe-particle-system-component 1.2.x
